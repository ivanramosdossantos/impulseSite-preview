# Impulse — site Preview

Cópia isolada da branch `feature/site-commercial-redesign` em `ivanramosdossantos/impulseSite` para validar o redesign comercial.

## Ativar GitHub Pages

1. Abra **Settings → Pages** deste repositório.
2. Em **Build and deployment → Source**, selecione **Deploy from a branch**.
3. Em **Branch**, escolha `main` e `/(root)`, depois clique em **Save**.
4. Acesse https://ivanramosdossantos.github.io/impulseSite-preview/ após o deploy ficar pronto.

## Proteções

- Nenhum arquivo `CNAME` de produção; assets e URLs com base `/impulseSite-preview/`.
- Sem analytics, tags GTM, envio de contatos ou cadastro real no Preview.
- Páginas com meta `noindex`; demonstração com dados fictícios.
- O repositório de produção `ivanramosdossantos/impulseSite` e seu PR #8 não foram alterados.
